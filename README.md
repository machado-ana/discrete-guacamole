# Discrete Guacamole 🥑

## Overview

This repository tracks my progress and studies in **Haskell** for the **Discrete Mathematics** course, split into three main tracks:

- **Learning** — practical files and exercises based on the lecture notes provided by the professor and video lectures by professor João Paulo.
- **Sets** — problem sets solved throughout the course.

Reference: [Professor João Paulo lectures](https://www.youtube.com/watch?v=fx5gZzs5lWg&t=90s) 

Repository status: in progress. New problem sets, tests, and notes are added as the course moves forward.

## Running locally

To run the code, you will need the [GHC (Glasgow Haskell Compiler)](https://www.haskell.org/ghcup/) installed on your machine.

```bash
# Load a file in the GHC interactive environment (REPL)
ghci learning/aula01.hs
```
